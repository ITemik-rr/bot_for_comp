# bot_for_comp

Telegram‑бот для мониторинга основных ресурсов компьютера: памяти, CPU, количества процессоров и свободного места на дисках.

## 🧠 Возможности

Бот умеет:
*   **Мониторинг памяти** — показывает процент использования оперативной памяти и краткий комментарий о нагрузке.
*   **Информация о процессорах** — выводит количество логических и физических ядер.
*   **Загрузка CPU** — измеряет текущую загрузку процессора (за 1 секунду).
*   **Статистика по дискам** — отображает общий и свободный объём места на диске в удобном формате (KB, MB, GB и т.д.) и процент занятого пространства.
